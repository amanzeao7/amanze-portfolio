How We Think

Before we build anything, we ask

These six questions turn a vague idea — "we need a new website" or "we need this automated" — into a system that actually holds up under real business conditions.

01

What's this process actually costing you right now — time, money, or lost customers?

02

What systems are you using, and do they actually talk to each other?

03

What needs a human decision, and what can be automated safely?

04

What's the smallest system that actually solves this — not the most impressive one?

05

What happens when it breaks, or the data's wrong?

06

Who owns this once it's live — you, or do you need it managed for you?

The goal isn't to sell you the most technology. It's to build the smallest system that solves the real problem — and make sure it still works long after we've delivered it.

Refresh Health Club

Connected Systems — Multi-Location Pilates

The Problem

Refresh was expanding to three locations (Reading, Pangbourne, Wokingham) but had no way to manage location-specific pricing, schedules, or booking availability. Their booking platform, website, and admin processes weren't connected — meaning manual reconciliation, an outdated site, and no reliable lead capture.

The System We Built

A custom multi-location architecture — dedicated location pages with independent pricing, schedules, and instructor profiles, all sitting on one connected backend. Integrated the MindBody/Healcode booking API for real-time availability across every site. Built a capture-optimised enquiry funnel, hardened security, and handled the full DNS migration.

The Outcome

✓ Multi-location management centralised into one system
✓ Booking friction eliminated across all three sites
✓ Lead capture doubled
✓ Class bookings & retention significantly higher
✓ 2+ year ongoing retainer relationship

Systems Used

Custom Backend • MindBody/Healcode API • Multi-Location Architecture • Security Hardening

Bracknell Third Spaces

Connected Systems — Community / Civic

The Problem

A council-backed community initiative was creating accessible public spaces, but had no centralised system for discovery, information, or bookings — meaning local residents didn't know these spaces existed, and staff had no reliable way to track enquiries or reservations.

The System We Built

An information-architecture-first platform built for discovery: comprehensive space profiles with availability calendars, a connected booking and enquiry system, and event pages with clear next steps. Built accessibility (WCAG compliance, semantic HTML) in from the start, with a simple backend that non-technical council staff can manage across multiple spaces.

The Outcome

✓ Community awareness increased significantly
✓ Booking enquiries centralised & trackable
✓ Council now has a scalable platform for future initiatives
✓ Became the model for other community projects
✓ Ongoing relationship with Bracknell Council

Systems Used

Next.js • Sanity CMS • Vercel • Accessibility-First • Booking Integration

Marcianno Bexley & District ABC

Web Presence — Boxing Club, Zero to Launch

The Problem

A growing amateur boxing club had no online presence at all — meaning no way to attract new members, showcase the offering, or take bookings for classes, while competing against established gyms with proper systems in place.

The System We Built

A full site built from the ground up: live class timetables, membership tier pricing, instructor profiles, and a Bookwhen integration for seamless class booking — designed so non-technical staff could run it day to day, with a visual identity that reflects the club's energy without looking amateur.

The Outcome

✓ Professional presence launched from zero
✓ Class bookings now managed entirely through the site
✓ New member enquiries traceable & systemised
✓ Competitive positioning against established gyms
✓ Strong foundation for future features

Systems Used

WordPress • Bookwhen API • Responsive Design • Membership Integration
